One line: a one-star review of Monday, written as if Monday were a restaurant. The diner ordered the weekend and got Monday served instead — cold, undercooked, and the bill came with four more days attached.

## Run it

```sh
node main.ts
```

This writes the review to `out/entry.txt` (override the output directory with `MAKEFUN_OUTPUT_DIR`).
